# خطة المرحلة الثانية

## الهدف

تحويل التطبيق من ملف تشغيل متراكم إلى وحدات ES Modules، مع إبقاء تجربة عيد الميلاد نفسها: المشاهد، ترتيبها، النصوص، الصور، البيانات، التفاعلات، والأنيميشن.

## الترتيب المنفذ

1. إنشاء مدخل module في `src/app/main.js`.
2. إنشاء `SceneManager` لعزل ترتيب المشاهد والانتقال بينها.
3. نقل المشاهد إلى ملفات مستقلة مع واجهة استدعاء موحدة تستقبل `app` وcallbacks الانتقال.
4. نقل البيانات إلى `src/data/` وتحديث fetch paths دون تغيير محتوى JSON.
5. وضع أدوات Canvas المشتركة، ومنها polyfill `roundRect`.
6. إبقاء النسخة السابقة في `legacy/` للاسترجاع والمقارنة.
7. فحص الصياغة، المسارات، الخادم الثابت، وتحميل كل مشهد في Chromium.

## حدود المرحلة

هذه ليست مرحلة إعادة تصميم أو تحسين Responsive Design. لم يتم تغيير الألوان أو النصوص أو ترتيب المشاهد، ولم تتم إضافة مكتبات أو build system.
